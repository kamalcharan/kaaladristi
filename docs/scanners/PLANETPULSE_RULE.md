## What PlanetPulse Is

PlanetPulse is the **earliest signal in the entire DristiQ intelligence chain** — a forward-looking planetary calendar that answers three questions before any price or volume signal fires:

```
WHAT:   Which stocks and sectors were historically impacted
        when this planet was in this position before?

HOW:    Positive or negative, magnitude, duration,
        which DristiQ scanner signal eventually fired?

WHEN:   Next occurrence of the same configuration —
        how many days away, and what is the expected lag
        between planetary event and market/sector move?
```

PlanetPulse does not replace technical or fundamental analysis. It is the **90-day extended weather forecast** — the season-level view that tells you which sectors to watch before Waking Giants, Strategic Rebirth, or Flower Pot Burst signals appear.

## Conceptual Foundation — Planetary Domain Intelligence

Each planet governs a domain of human activity. When a planet moves — ingress into new sign, conjunction with another planet, retrograde station, opposition — it **amplifies or restricts** that domain. This creates observable patterns in which sectors receive capital, which face stress, and which dormant companies suddenly become strategically relevant.

This is not prediction. It is **pattern intelligence from recorded history** — the same way a meteorologist reads pressure systems, not individual raindrops.

### Positive vs Negative — The Correct Framing

Most astro-trading systems make the error of labeling planets good or bad. PlanetPulse does not.

Every planet is **positive for some sectors and negative for others simultaneously:**

```
Mars strong (ingress Aries, Mars-Jupiter conjunction):
  POSITIVE: Defence orders, steel, mining, energy — Mars amplifies
  NEGATIVE: Consumer sentiment (conflict fear), volatile markets

Saturn station retrograde:
  POSITIVE: Infrastructure companies, debt-reduction plays,
            long-term contract businesses (Saturn rewards patience)
  NEGATIVE: Growth stocks, expansion plays, new ventures,
            anything requiring quick execution

Rahu ingress new sign:
  POSITIVE: New sign's theme sectors (obsession = excess demand)
  NEGATIVE: Ketu's sign sectors (abandonment = excess supply)

Jupiter retrograde:
  POSITIVE: Value investing, fundamental revisiting,
            quality businesses (Jupiter wisdom turns inward)
  NEGATIVE: New IPOs, growth-at-any-price, expansion narratives

Herschel station:
  POSITIVE: Technology disruption plays (ride the wave)
  NEGATIVE: Legacy incumbents in disrupted sectors

Saturn in Pisces:
  POSITIVE: Fluid handling, safe transfer (scarcity = demand for
            reliable infrastructure), water treatment
  NEGATIVE: Maritime shipping (disruption = cost/delay),
            oil & gas (supply restriction)
```

## Signal Architecture — Four Signal Types

### PP_SECTOR_ALERT
**Planetary configuration actively impacting a sector right now.**

```
Trigger: Active planetary configuration in km_astro_observation_windows
         matches sector in km_sector_theme_map

Output:
  planet_name
  configuration           -- "IN_PISCES", "STATION_RETRO" etc
  configuration_start     -- when it began
  configuration_end       -- when it ends (from ephemeris)
  days_remaining          -- how long window still open
  
  sector_impact:
    sectors_positive[]    -- sectors historically benefiting
    sectors_negative[]    -- sectors historically stressed
    magnitude_positive    -- avg % move in positive sectors
    magnitude_negative    -- avg % move in negative sectors
    typical_lag_days      -- avg days from planet event to sector move
    
  confidence_tier         -- VALIDATED / INDICATIVE / HISTORICAL_PATTERN
  impact_type             -- MARKET_VALIDATED / GEO_ONLY / HYBRID
  
  waking_giants_watch[]   -- dormant stocks in positive sectors
                             already showing GL accumulation
  strategic_rebirth[]     -- stocks with active PEAD in positive sectors
```

### PP_STOCK_WATCH
**Specific stocks that moved during previous identical planetary configuration.**

```
Trigger: km_planet_impact_history has correlated_stocks
         for current configuration
         AND those stocks currently meet dormancy criteria

Output:
  symbol
  planet_configuration    -- what was active when it moved before
  previous_occurrence:
    start_date
    signal_fired          -- WAKING_GIANT_P1, SR_PEAD_ACTIVE etc
    lag_days              -- days from planet event to signal
    move_pct              -- total move during window
    hold_days             -- how long move lasted
  
  current_status:
    stage_classification
    gl_acc_days
    heatmap_5d_green
    heatmap_22d_green
    days_below_3yr_high
    
  watch_reason:           -- "Moved +85% during last Saturn-Pisces.
                             Currently in Stage 1, GL accumulation
                             at 8 days. Saturn-Pisces still active
                             for [N] more days."
```

### PP_FORWARD_EVENT
**Upcoming planetary events in the next 90 days with historical sector impact.**

```
Trigger: km_ephemeris data showing planet movements
         within next 90 days
         Cross-referenced with km_planet_impact_history

Output per upcoming event:
  planet_name
  event_type              -- INGRESS / CONJUNCTION / STATION /
                             RETROGRADE / OPPOSITION / RETURN
  event_date              -- exact date from ephemeris
  days_from_today         -- countdown
  sign_entering           -- for ingress events
  planets_involved[]      -- for conjunctions/oppositions
  
  historical_impact:
    sectors_to_watch[]
    avg_lead_days          -- sector moves N days AFTER planet event
    avg_magnitude          -- typical % move in impacted sectors
    previous_occurrences[] -- dates of historical instances
    confidence_tier
    
  action_ahead:
    "Begin scanning [sectors] for dormant stocks
     [N] days before this event.
     Historical: sector moved avg [X]% in [Y] days after."
     
  current_waking_giants[] -- dormant stocks in those sectors NOW
  current_sr_candidates[] -- rebirth candidates in those sectors NOW
```

### PP_GEO_ONLY
**Outer planet / multi-decade cycle signals — narrative intelligence only.**

```
Trigger: Herschel, Neptune, Pluto movements
         OR any configuration with geo_only_flag = TRUE

Output:
  planet_name
  configuration
  cycle_years             -- 84 / 165 / 248 years
  historical_precedent:
    period_name           -- "Herschel in Taurus 1935-1942"
    key_events[]          -- documented geopolitical events
    sector_themes[]       -- what thrived, what collapsed
    
  current_parallel:
    period_name           -- "Herschel in Taurus 2018-2026"
    observed_events[]     -- COVID, supply chains, banking stress
    sector_themes[]       -- what has thrived, what collapsed
    
  transition_ahead:
    entering_configuration -- "Herschel entering Gemini ~2026"
    expected_themes[]     -- new era sector rotation
    sectors_peaking[]     -- Taurus winners to exit
    sectors_emerging[]    -- Gemini winners to seed
    
  prominent_disclaimer:
    "GEO/NARRATIVE ONLY — No statistical validation possible.
     Pattern intelligence from [N]-year historical cycle.
     For thesis development and sector rotation awareness only."
```

## Confidence Framework — Strict Separation

```
MARKET_VALIDATED:
  NSE price/sector data confirms correlation
  n≥3: VALIDATED (statistical basis)
  n=2: INDICATIVE (promising, needs more data)
  n=1: UNVALIDATED (single observation, watch only)
  Use for: All signals, entry timing guidance

GEOPOLITICAL_OBSERVATIONAL:
  Pattern observed in geo events, no market data
  Multiple historical instances: HISTORICAL_PATTERN
  Use for: Sector rotation thesis, narrative intelligence
  NOT for: Entry timing, statistical signals

HYBRID:
  Geo pattern (historical) + Market response (1990+)
  Example: Mars-Saturn → military conflict (historical)
           + defence sector +28% (NSE 2022)
  Label: INDICATIVE_HYBRID
  Use for: Sector alerts with explicit caveat

GEO_ONLY (Outer Planets):
  Herschel, Neptune, Pluto — cycles longer than NSE history
  Label: HISTORICAL_PATTERN
  Prominent disclaimer always shown
  Use for: Long-horizon thesis ONLY
```
